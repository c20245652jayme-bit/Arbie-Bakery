Arbie's Bakery

**Live site:** https://c20245652jayme-bit.github.io/Arbie's Bakery-/

## About

Arbie's Bakery is a simple one-page website for a local bakery that offers freshly baked bread, delicious cakes, and sweet pastries. It helps customers learn about the bakery and contact the business.
## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |

| Secondary | 30% | `##E8C9A0` | Cards, sections, navigation |
| Accent | 10% | `##8B5E3C` | Buttons, links, highlights |

### Visual style
Minamlism(simple and clean design)
**Style chosen:** (for example: minimalism, glassmorphism, neo-brutalism, bento grid)

**Why I chose it:** one sentence.
I chose minimalism because it makes my bakery website look clean, simple, and easy for visitors to navigate.
